# How to Test the FreeCAD TechDraw Worker

## Quick Test

### Step 1: Run the Pipeline

The pipeline now automatically uses the FreeCAD TechDraw worker. Just run:

```powershell
# From CAD-MVP root
cd cad_view_agents
python run_pipeline.py ..\web\uploads\f274b5d997e9470a910dcd5bd21c30b3_Pump_Manifold_v3.step
```

### Step 2: Check Output

After the pipeline runs, check:

1. **Drawing Plan**: `output\asm_<id>\drawing\drawing_plan.json`
   - Contains all view, BOM, and balloon data

2. **PDF Output**: `output\asm_<id>\drawing\drawing.pdf`
   - Generated by the TechDraw worker

3. **Worker Logs**: `output\asm_<id>\drawing\render.log`
   - Contains worker execution logs and any errors

### Step 3: Verify Worker Execution

Look for these messages in the pipeline output:
```
[6/8] Using FreeCAD TechDraw worker...
  [OK] Saved drawing plan: output\asm_<id>\drawing\drawing_plan.json
  [INFO] Running worker (attempt 1/2)...
  [OK] Worker generated PDF: output\asm_<id>\drawing\drawing.pdf
[Export] PDF already generated by FreeCAD TechDraw worker
```

## Troubleshooting

### Worker Fails

1. **Check render.log**:
   ```powershell
   Get-Content output\asm_<id>\drawing\render.log
   ```

2. **Common Issues**:
   - FreeCAD not found: Ensure FreeCAD is installed and `run_pipeline.py` can find it
   - STEP import fails: Check that the STEP file is valid
   - TechDraw not available: Ensure FreeCAD has TechDraw module

### Worker Times Out

- Default timeout is 5 minutes (300 seconds)
- Check `render.log` for what the worker was doing when it timed out
- Worker will retry once automatically

### No PDF Generated

- Check `render.log` for errors
- Verify FreeCAD TechDraw module is available
- Check that the output directory is writable

## Manual Worker Test

You can also test the worker directly (if needed for debugging):

```powershell
# First, run pipeline to generate drawing_plan.json
python run_pipeline.py ..\web\uploads\<step-file>.step

# Then run worker manually (using FreeCAD's Python)
& "C:\Program Files\FreeCAD 1.0\bin\python.exe" render_workers\freecad_techdraw_worker.py `
  output\asm_<id>\drawing\drawing_plan.json `
  ..\web\uploads\<step-file>.step `
  output\asm_<id>\drawing
```
